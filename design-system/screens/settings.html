Default model

Foundation model used for Generate Review and Refine. You can override per call. Lighter tiers (fast) respond quicker and cost less. Models marked "(reasoning)" think before answering for higher accuracy.

Exam import model

Foundation model used to extract questions from uploaded exam files (PDF/MD/ZIP). A stronger model reduces extraction failures on messy source files, at higher cost and latency per question.

AI import review ("Refine with AI")

Model and limits used when the AI writes explanations for imported questions.

A question that gets no answer within the max wait is retried once, then marked as failed. Higher waits and more parallel calls finish large batches sooner but can hit Bedrock quotas; you only pay for the time actually used.

Interface language

Language the app's own screens, buttons, and menus are shown in.

Output language

Language used in explanations and translations. Default keeps the same language as the input question or transcript.

Translation language

Language the "Translate with AI" button targets. Automatic uses your interface language, unless the question is already in that language — then it falls back to Portuguese, or English.

Default review mode

Choose whether the New Question screen starts in "Generate with AI" mode or "Add ready-made review" mode. You can switch modes at any time on the screen itself.

Question review

Highlight the correct alternative in green when reviewing a question. Turn this off to review without seeing the answer marked.

Quiz timer

Default state of the timer toggles on the quiz setup screen (only shown for exams with timing configured in the pack editor). You can still change these per quiz.

Workspace tabs

Choose which tabs appear in a certification workspace, and reorder them with the arrows. At least one must stay visible.

Quiz toolbar

Choose which buttons appear in the quiz question toolbar, and reorder them with the arrows.
