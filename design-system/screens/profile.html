MongoDB Associate Data Modeler

MongoDB certification focused on designing data structures and applying MongoDB design patterns. Given data requirements, query needs, and constraints, the candidate selects the pattern that best fits the use case (embed versus reference, and the 12 MongoDB schema design patterns). Covers requirements gathering, entities, relationships, workload analysis, data model design, modeling for technical requirements, indexing, and monitoring/evolving data models. Online proctored exam, 70 multiple-choice questions (60 scored), 105 minutes, 70% passing score.

MongoDB certification validating the skills to build applications using MongoDB and a supported driver.
