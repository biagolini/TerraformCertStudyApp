Index

Compute

Pick the compute option by how much of the server you want to manage.

Virtual machines

Full control of the operating system; you patch, scale and pay per running hour.

Instance families

  • General purpose: balanced CPU and memory for web and app servers.
  • Burstable types suit low, spiky traffic.
  • Compute optimized: batch jobs, media encoding, high-traffic APIs.
  • Memory optimized: in-memory caches and large databases.

Serverless functions

Code runs per request and scales to zero; billed per invocation and duration.

Key takeaway: if the scenario says "no servers to manage" and short tasks, think serverless functions.

Storage

Object storage

Durable storage for files of any size, addressed by key, with lifecycle rules to move old data to cheaper classes.

Block storage

A disk attached to one virtual machine; snapshots copy it to another zone.

Private networks

Content delivery
